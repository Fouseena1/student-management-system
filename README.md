# Student Management System

A simple Student Management System built using Python and SQLite.

## Features

- Add student
- View all students
- Update student details
- Delete student
- Search student
- Course management
- Foreign key relationship
- Input validation
- Menu-driven interface

## Technologies Used

- Python
- SQLite
- SQL
- Git & GitHub

## Database

The project uses two tables:

- `students`
- `courses`

The `students` table is connected to the `courses` table using a foreign key.

## How to Run

1. Clone the repository.
2. Open the project in PyCharm.
3. Run `main.py`.
4. Select an option from the menu.

## Menu

1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Search Student
6. Exit
